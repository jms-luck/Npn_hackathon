# API

Interactive OpenAPI documentation is available at `/docs` while FastAPI is running.

Main route groups:

- `/api/auth`: registration, login, and current user.
- `/api/companies`: company lookup.
- `/api/jobs`: active jobs and candidate application submission.
- `/api/candidate`: profile, resumes, applications, and recommendations.
- `/api/recruiter`: company-owned jobs, applicants, matching, and interviews.
- `/api/resumes`: private upload, authorized download URL, and deletion.
- `/api/interviewer`: assigned candidates and feedback.
